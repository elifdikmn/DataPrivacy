# Legacy

Bu klasördeki dosyalar eski, bozuk RAG chatbot denemesinden kalma kod. Yeni backend `backend/app/` altında sıfırdan yazılıyor. Buradaki dosyalar sadece referans/arşiv amaçlı tutuluyor, aktif olarak kullanılmıyor.

- `llm_handler.py` — eski FastAPI + FAISS + SBERT + Together API tabanlı backend.
- `package-lock.json` — bu klasöre nasıl geldiği belirsiz bir npm lockfile (Python backend'de kullanılmıyor).
